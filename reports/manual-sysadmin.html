1. System Overview

The HWA Smart Metering Portal is a Yii 2 PHP web application hosted on AWS. It receives IoT water-meter readings via a ThingsBoard webhook, allows billing clerks to review and approve readings, and pushes approved readings to the core billing server (reading.hargeisawatertech.com) for invoice generation.

DomainPurpose
portal.hargeisawatertech.comFull admin/clerk portal (all modules)
billing.hargeisawatertech.comBilling module only (restricted access)
api.hargeisawatertech.comREST API for ThingsBoard & mobile apps
reading.hargeisawatertech.comExternal HWA Core Billing API (remote)

  • ThingsBoard pushes telemetry via REST webhook to api.hargeisawatertech.com.
  • The portal stores raw readings in its local MySQL database (nobleus).
  • Billing clerks review and approve readings on the portal.
  • Approved readings are pushed to reading.hargeisawatertech.com/bill/api/meter-reading.
  • The core billing server writes invoices to the on-premise PostgreSQL database.

7. Billing Date Policy (28th Rule)

Company Policy All meter readings posted to the core billing server use the 28th of the reading's month as the official billing date, regardless of when the reading was physically taken.

This policy is enforced in code in two places:

  • Bulk post (actionPostToBilling) — uses $month . '-28' as the target date.
  • Single post (actionImport) — derives date('Y-m', ...) . '-28' from the reading's timestamp.

If the reading was taken on a different day (e.g., the 7th), a description field is automatically appended to the API payload noting the actual reading date. This note appears in the core billing system for auditors.

8. Deployment & Upgrade

8.1 First-time setup

  1. Clone the repository: git clone git@github.com:apitab/nobleus-admin.git /home/admin/nobleus-admin
  2. Copy and edit the environment file: cp .env.example .env && nano .env
  3. Install PHP dependencies: composer install --no-dev --optimize-autoloader
  4. Run database migrations: php yii migrate
  5. Set web directory permissions: chmod -R 775 backend/web/assets backend/runtime common/runtime
  6. Enable Apache vhosts and reload: a2ensite portal.hargeisawatertech.com-le-ssl.conf nobleus-ssl.conf api.hargeisawatertech.com.conf && sudo systemctl reload apache2

8.2 Code upgrade

cd /home/admin/nobleus-admin
git pull origin main
composer install --no-dev --optimize-autoloader
php yii migrate                # apply any new migrations
sudo systemctl reload apache2  # reload Apache (view changes take effect immediately)
Note PHP view files take effect on the next page load without a restart. Only Apache config changes require reload.

10. Troubleshooting Reference

billing_audit_logs empty Table missing (old install) Run php yii migrate to create the table

11. Security Checklist

  • Rotate CORE_API_TOKEN every 6 months or after any staff departure.
  • Rotate TB_WEBHOOK_TOKEN every 6 months.
  • Keep .env permissions to 640 (owner read/write, group read only).
  • Ensure YII_DEBUG=false and YII_ENV=prod in production index.php.
  • SSL certificates must not expire — set up auto-renewal cron: 0 3 * * * certbot renew --quiet.
  • Restrict MySQL user nobleus to localhost only.
  • The catch-all Apache vhost blocks all bare-IP access — do not disable it.
  • Enable AWS Security Group rules: allow 80, 443 inbound; restrict 22 (SSH) to trusted IPs.
